# List lệnh
- <kbd>Ctrl</kbd> + <kbd>a</kbd> + <kbd>d</kbd>: detach all session 
- <kbd>Ctrl</kbd> + <kbd>a</kbd> + <kbd>Ctrl</kbd> + <kbd>d</kbd>: delete all session

- Các phím tắt cho session

    | STT | Lệnh | Tác dụng |
    | --------------- | --------------- | --------------- |
    | 1 | tsn | Tạo session mới |
    | 2 | tsr | Đổi tên session |
    | 3 | tsa | Attach session |
    | 4 | tsk | Kill session |
    | 5 | ctrl + a + s | List session |

- Các phím tắt cho windown

    | STT | Lệnh | Tác dụng |
    | --------------- | --------------- | --------------- |
    | 1 | twn | Tạo windown mới |
    | 2 | twr | Đổi tên windown |
    | 3 | ctrl + a + w | List windown |
    | 4 | ctrl + a + x | Đóng windown hiện tại |
